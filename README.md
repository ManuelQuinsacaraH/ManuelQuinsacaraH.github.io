## Arquitectura

La versión actual es **100% estática**: `index.html` contiene directamente la página principal y ya no depende de Jekyll, `_includes` ni cadenas de reemplazos Liquid. Esto simplifica mantenimiento, auditoría y despliegue en GitHub Pages.

- 100.000+ SKU en universo operacional

- ~30% menos no conformidades asociadas a entregas
