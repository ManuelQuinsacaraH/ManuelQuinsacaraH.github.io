# Interactive Executive Resume - Manuel Quinsacara Herrera

## Contenido
- index.html: perfil interactivo bilingüe ES/EN.
- assets/Perfil_Profesional_Manuel_Quinsacara.pdf: perfil ejecutivo en PDF.
- assets/CV_ATS_Manuel_Quinsacara.docx: CV ATS.

## GitHub Pages
1. Crea un repositorio llamado `TUUSUARIO.github.io`.
2. Sube `index.html` y la carpeta `assets`.
3. Ve a Settings > Pages.
4. Selecciona Deploy from a branch.
5. Branch: `main`; folder: `/ (root)`.
6. Guarda.
7. El sitio quedará en `https://TUUSUARIO.github.io`.

No se requiere framework, Node.js ni dependencias externas.
