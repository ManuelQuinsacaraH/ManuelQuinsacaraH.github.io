# Checklist de publicación

Antes de subir:

- [ ] Respaldé la versión anterior del repositorio.
- [ ] Subiré todos los archivos y carpetas del paquete, incluida `.nojekyll`.
- [ ] Eliminaré `_includes/` y otros archivos antiguos que ya no formen parte del paquete.
- [ ] Verifiqué que `assets/profile.webp` esté presente.

Después de publicar:

- [ ] La página principal abre sin errores.
- [ ] El desplazamiento y la barra de progreso funcionan.
- [ ] ES / EN cambia todos los textos visibles.
- [ ] El botón ATS abre/descarga el PDF correcto según el idioma.
- [ ] El Perfil Profesional abre correctamente.
- [ ] El botón Portafolio funciona desde hero y cierre.
- [ ] Email funciona.
- [ ] WhatsApp abre el número correcto.
- [ ] LinkedIn abre el perfil correcto.
- [ ] El contact dock no tapa contenido en desktop.
- [ ] La barra de contacto móvil no tapa botones o texto.
- [ ] La web se ve correctamente en teléfono y escritorio.
